## 💡 Pro Tips

### **Do's:**
✅ List skills you've actually used in projects
✅ Prioritize skills mentioned in job description
✅ Use industry-standard terminology
✅ Group related skills together
✅ Include version numbers for major tools (Python 3.11, React 18)
✅ Mention both frameworks AND underlying concepts

### **Don'ts:**
❌ Don't list every technology you've touched once
❌ Don't use vague terms like "familiar with computers"
❌ Don't lie about proficiency levels
❌ Don't include outdated technologies (unless relevant)
❌ Don't use graphics/charts in ATS-friendly resumes
❌ Don't list soft skills in technical skills section

### **ATS Optimization:**
- Use exact keywords from job description
- Spell out acronyms first: "Natural Language Processing (NLP)"
- Use standard section headers: "TECHNICAL SKILLS" or "SKILLS"
- Avoid tables and complex formatting for ATS parsing
- Use bullet points for readability
